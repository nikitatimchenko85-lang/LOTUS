# LOTUS

Приложение Lotus Arena (Пхукет) для склада оборудования, выездных сетапов, погрузки траков и смет.

## Что умеет

- **Склад.** Оборудование по позициям: количество, ремонт, место хранения, размеры и вес кейса, стоимость и амортизация. Свободное количество считается с учётом сетапов, пересекающихся по датам.
- **Сетапы.** Площадка, даты, статус, оборудование, траки, бригада, прочие расходы.
- **Погрузка.** Раскладка кейсов по полу трака (вид сверху) с учётом штабелирования, веса и грузоподъёмности. Порядок обратный монтажу: риггинг и сцена грузятся последними и стоят у дверей. Подбор траков и общий чек-лист «погружен / выгружен / вернулся на склад».
- **Финансы.** Смета по сетапу: аренда (коэффициент следующих дней, скидка), работы, логистика (дни и км), прочее, НДС 7%. Внутренний учёт амортизации.

## Роли

| | Руководитель | Склад и логистика | Только просмотр |
|---|---|---|---|
| Склад, сетапы, автопарк | меняет | меняет | смотрит |
| Чек-лист погрузки | отмечает | отмечает | смотрит |
| Цены, стоимость, амортизация, сметы | видит и меняет | скрыто | скрыто |

Сейчас роли берутся из уровня доступа к странице в Claude: Editor соответствует руководителю, Contributor складу и логистике, Viewer просмотру. Денежные данные лежат в отдельной коллекции `fin`, которую хранилище отдаёт только руководителю.

## Как запускать

- `src/lotus.html` — исходник страницы, опубликованной в Claude (данные в общем хранилище страницы).
- `index.html` — та же страница как отдельный файл. Вне Claude открывается в демо-режиме с примерами и без сохранения.

## Данные

Коллекции: `items`, `trucks`, `events` (без денег) и `fin` (деньги: документы `item-<id>`, `truck-<id>`, `event-<id>`).

`import/equip.tsv` — 137 позиций из таблицы «Тай - прайс, парк и амортизация оборудования» (лист «Оборудование»). `import/build.py` собирает из неё документы. Размеры и вес кейсов пока оценочные (`dimsEst: true`), их нужно уточнить.

## Конструктор сетапов

`constructor/index.html` — отдельная страница (позже станет вкладкой LOTUS). Задаёте размеры площадки и сцены, расставляете оборудование со склада на плане сверху, смотрите вид из зала. Страница считает:

- количество оборудования по складу, с остатком; автоматически добавляет подиумы под сцену, лебёдки под фермы, рамы под линейные массивы и кабельные мосты до FOH;
- фермы: рисуются ломаной с прилипанием концов, T-узлами и опорами-граундом, есть готовые формы; считаются метры, секции по длинам со склада, кубы, комплекты соединителей (конусы, пальцы, шплинты), базовые плиты и лебёдки;
- слои по отделам: показать, скрыть, только один, заблокировать;
- кабели по типам (фидеры, питание 16 А, DMX, акустика, XLR, EtherCON, SDI): число линий, длину трассы и нарезку стандартными длинами с запасом.

Каталог встроен в страницу из `import/equip.tsv` (id совпадают с `items`). Сетап сохраняется в браузере и в JSON-файл. Мощности приборов и правила разводки пока оценочные.
